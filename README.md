## 📌 About The Project

The idea of the project was to create a personal resume website using Angular.

The application demonstrates:

- Angular application structure;
- component-based architecture;
- working with TypeScript;
- creating reusable UI components;
- organizing frontend application logic.

## 🚀 Getting Started

### Prerequisites

- Node.js
- npm
- Angular CLI

### Installation

Clone the repository:

```bash
git clone https://github.com/OlgaZaglavnova/ResumeAngular.git
```

Navigate to the project folder:

```bash
cd ResumeAngular
```

Install dependencies:

```bash
npm install
```

Run the application:

```bash
ng serve
```

Open the application:

```
http://localhost:4200/
```
